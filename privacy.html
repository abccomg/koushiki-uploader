プライバシーポリシー

koushiki-uploader は、運営者本人の YouTube チャンネルに動画をアップロードし、プレイリストに追加するためだけに Google アカウントへのアクセス（YouTube Data API）を使います。

  • 取得した認証情報は運営者の PC にのみ保存し、上記の目的以外には使いません。
  • データを第三者に提供・販売することはありません。
  • Google アカウントの「サードパーティ製のアプリとサービス」から、いつでもアクセスを取り消せます。

本ツールによる Google API から受け取った情報の使用は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。
